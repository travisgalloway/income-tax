# Interface: curated snapshots (`src/data/debt_holders.json`, `debt_maturity.json`, and siblings)

The consumer contract for datasets whose `_meta.refresh.mode` is `"curated"`: `debt_holders`,
`debt_maturity`, `income_tax_by_group`, `oecd`. These are generated by
`pipeline/monthly/curated_snapshots.py` from `pipeline/curated/snapshots.yaml` plus the editorial
resolutions in `pipeline/curated/discrepancies.yaml` — they are **never auto-fetched**. Read this
before charting from any of them; the failure modes below are silent otherwise.

## The `refresh.mode: curated` shape

```json
"_meta": {
  "refresh": { "mode": "curated", "reason": "source publishes as a document, not a machine-readable feed" }
}
```

`Meta.refresh` (`src/data/types.ts`) reaches this field through a narrowed optional property, not
a cast through the index signature.

## The freshness gap and `curatedVintage()`

`vintageOf(meta)` (`src/data/index.ts`) returns `null` for a curated snapshot: it has neither
`provenance.vintage` nor `provenance.retrieved_at`, because nothing was fetched. Passing a curated
dataset's `_meta` to `vintageOf` silently ships a figure with **no freshness stamp at all** — the
gap named as edge case 1 in issue #6.

Use `curatedVintage(meta, asOf)` instead, passing the dataset's own as-of date (e.g.
`debtHolders.data.as_of`, `debtMaturity.data.avg_maturity_as_of`):

```ts
curatedVintage(debtHolders._meta, debtHolders.data.as_of)
// "Curated snapshot, as of 7 August 2026. Refreshed by hand, not auto-fetched."
```

It throws if called on a dataset whose `_meta.refresh.mode` is not `"curated"` — a guard against
copy-pasting it onto a fetched dataset, where `vintageOf` is correct.

## `deliberate_omissions`

`debt_holders._meta.deliberate_omissions` names data that was deliberately left out, keyed by the
`discrepancies.yaml` resolution that omitted it (currently `federal_reserve_holdings`). This is
metadata for anyone reading the JSON, not something a component renders — the omission itself must
also never resurface silently if a future fetcher starts supplying the figure (`validate.py`'s
`check_snapshots` fails the build if the string `"federal reserve"` appears anywhere in
`debt_holders.data`).

## The denominator rule (`share_of_public_pct` vs `share_of_gross_pct`)

`debt_holders.data.public_split` uses the field name `share_of_public_pct`, deliberately not
`share_pct` — the denominator is part of the field name so a renderer cannot flatten it to a bare
percentage. The complementary gross-debt figure lives at
`foreign_share_history[-1].share_of_gross_pct` (30% of publicly held debt, 24% of gross debt as of
2025) and must **never** be recomputed; both figures come from
`discrepancies.yaml -> foreign_share_of_debt`, which is the only place they are allowed to be
picked. A consumer presenting either share must name its denominator in the same string — one
formatter, reused by the chart, the `aria-label`, the live-region readout and the table.

## The non-partition rule

`debt_maturity.data.composition` (bills, notes, bonds) does **not** sum to
`marketable_total_t`: `6.8 + 15.9 + 5.4 = 28.1` against a curated total of `28.0`. Separately,
`bills.share_pct` (`22`) disagrees with `bills.amount_t / marketable_total_t` (`24.3%`) — the
curated share and the curated amount are two independently-sourced figures that do not reconcile
to each other. The rule this dataset imposes on any renderer:

- Bar/band **geometry** comes from `amount_t`.
- A **percentage** is rendered only where the curated data supplies a `share_pct` field (bills
  only, currently) — never derived as `amount_t / marketable_total_t`.
- The composition is never presented as an exhaustive partition of the marketable total; the gap
  must be stated in the figure's `note`.

## `history_months` — present, deliberately unrendered

`debt_maturity.data.history_months` is a four-point maturity time series. `sections.md` §3 is
explicit that this section is not built as a time series — the finding is the gap between two
numbers (71 months average, 30-year maximum), not a trend. The field is kept in the data
(deleting curated data is a separate editorial act, out of scope for the issue that added this
contract) but no component may reference it; a test asserts `DebtMaturity.tsx` does not.

## `Dataset<DebtHolders>` / `Dataset<DebtMaturity>`

Both are now typed (`src/data/types.ts`), replacing the earlier
`Dataset<Record<string, unknown>>` placeholder. See the interfaces themselves for field-level
comments — the two traps above (denominator, non-partition) are documented inline at the fields
they apply to, not just here.
